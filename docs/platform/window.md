# platform

Окно операционной системы: создание, размер, события.

## Назначение

Подсистема отвечает за одно — существование окна и связь с оконной системой. Она сообщает размер кадрового буфера, передаёт накопленные события и выдаёт нативный хендл окна графическому API.

## Публичный API

```cpp
struct PixelSize { std::uint32_t width, height; };
struct WindowEvents { bool close_requested, resized; };

class Window {
    WindowEvents poll_events();
    PixelSize pixel_size() const;
    void* native_handle() const;
};

std::shared_ptr<Window> create_window(std::string_view title,
                                      std::uint32_t width, std::uint32_t height);
```

## Границы

Подсистема не знает про графику. Она отдаёт `void*` и размер в пикселях; что с ними делает потребитель — её не касается.

Подсистема не владеет главным циклом. `poll_events` вызывается извне и возвращает произошедшее за кадр, а не вызывает обработчики.

Камера сюда не относится: положение наблюдателя и проекция — это рендеринг, см. [renderer](../renderer/renderer.md).

## Решения

**Размер в пикселях, а не в логических единицах.** На дисплее с масштабированием они расходятся, а кадровый буфер измеряется в пикселях. Подсистема сообщает то, что нужно рендереру, и не заставляет его пересчитывать.

**Нативный хендл — `void*`.** Тип платформы (`HWND`) в публичный заголовок не попадает: потребитель передаёт указатель графическому API, не разыменовывая его. Поэтому заголовок не подключает `windows.h` и остаётся кроссплатформенным.

**Состояние скрыто.** SDL3 не виден в заголовке: определение `Window::State` живёт в реализации. Заменa оконной библиотеки не затронет потребителей.

**Владение SDL — RAII.** Подсистема видео SDL инициализируется и выключается парно, вместе с временем жизни состояния окна. Отдельных вызовов инициализации у потребителя нет.

## Зависимости

SDL3, приватно. В публичном API её типов нет.

## Ограничение

Нативный хендл берётся по свойству Windows. Ветвление по платформам появится здесь при добавлении второй целевой платформы.
