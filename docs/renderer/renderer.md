# renderer

Графический контекст, кадр и камера.

## Назначение

Подсистема владеет графическим API и отправляет кадры на устройство. Игровой код не знает, какой API выбран и как устроены его ресурсы.

## Публичный API

```cpp
struct Vector3 { float x, y, z; };

struct Camera {
    Vector3 position, target, up;
    float field_of_view;
    float near_plane, far_plane;
};

class Renderer {
    void resize(std::uint32_t width, std::uint32_t height);
    void render(const Camera& camera);
};

std::shared_ptr<Renderer> create_renderer(void* native_window_handle,
                                          std::uint32_t width, std::uint32_t height);
```

## Границы

Подсистема не создаёт окно и не обрабатывает события. Она принимает готовый хендл и размер кадрового буфера, см. [platform](../platform/window.md).

Подсистема не знает про сущности мира. Сейчас она очищает кадр; отправка геометрии появится вместе с первым мешем.

## Решения

**Камера здесь, а не в подсистеме окна.** Положение наблюдателя и проекция — это матрицы вида и проекции, то есть рендеринг. Окно про них ничего не знает и знать не должно.

**Соотношение сторон не хранится.** Оно выводится из текущего размера кадрового буфера при построении матрицы проекции. Хранить его отдельно значило бы держать вторую копию того же факта.

**Хендл окна — `void*`.** Тип платформы не попадает ни сюда, ни в подсистему окна: он известен только реализациям обеих.

**Владение библиотекой — RAII.** `bgfx::init` и `bgfx::shutdown` парные и привязаны ко времени жизни отдельного типа, поэтому выключение не выполняется при неудавшейся инициализации.

**Одна область вывода.** Кадр очищается и предъявляется целиком. Разделение на проходы появится, когда появится что рисовать.

## Зависимости

bgfx и bx, приватно. В публичном API их типов нет: заголовок оперирует `Camera` и `void*`.

## Замечание о размере

bgfx требует сообщать об изменении размера кадрового буфера отдельно: смена размера окна сама по себе его не меняет. Поэтому `resize` вызывается из главного цикла, когда окно сообщило о событии.
