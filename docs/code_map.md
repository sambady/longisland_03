# Карта кода

Точка входа в репозиторий. Отвечает на вопрос «где что лежит» и ведёт к подробному описанию каждой подсистемы.

Карта перечисляет подсистемы, их назначение, расположение и зависимости. Устройство подсистемы описывает её собственный документ в `docs/<subsystem>/`.

## Статус

Первый милстоун: клиент открывает окно, инициализирует bgfx и рисует очищенный кадр. ECS, сети, стриминга и ассетов ещё нет.

## Слои

Зависимости направлены сверху вниз. Обратных зависимостей не бывает.

```text
game      → игровая логика
runtime   → мир, ECS, сеть, стриминг, ассеты
engine    → рендер, платформа, звук, физика, анимация
libraries → bgfx, SDL3, Jolt, glm, ...
```

Весь код лежит в `src/`. Слой — каталог внутри него и префикс CMake-таргета: подсистема `renderer` слоя `engine` живёт в `src/engine/renderer/` и собирается в таргет `engine_renderer` с алиасом `engine::renderer`.

Заголовки лежат рядом с реализацией. Публикуется корень `src/`, поэтому заголовок подключается с префиксом слоя: `#include <engine/renderer/renderer.h>`.

Направление зависимостей проверяется при конфигурации: `longisland_add_subsystem` отклоняет ссылку на слой выше собственного. Ошибка архитектуры проявляется как ошибка сборки, а не как замечание на ревью.

## Подсистемы

| Подсистема | Слой | Расположение | Назначение | Зависит от | Документ |
|---|---|---|---|---|---|
| core | engine | `src/engine/core/` | Версия сборки | — | — |
| platform | engine | `src/engine/platform/` | Окно, его размер и события | SDL3 | [platform](platform/window.md) |
| renderer | engine | `src/engine/renderer/` | Графический контекст, кадр, камера | bgfx, bx | [renderer](renderer/renderer.md) |

## Точки входа

| Что | Файл |
|---|---|
| Клиент | `src/client/main.cpp` |
| Сборка | `CMakeLists.txt`, `CMakePresets.json` |
| Правила сборки | `cmake/` |

## Сборка

| Файл | Назначение |
|---|---|
| `cmake/Subsystem.cmake` | `longisland_add_subsystem` — объявление подсистемы и проверка слоёв |
| `cmake/CompilerWarnings.cmake` | `longisland::warnings` — предупреждения для своего кода |
| `cmake/Sanitizers.cmake` | `longisland::sanitizers` — ASan и UBSan |
| `cmake/deps/` | по файлу на внешнюю зависимость: версия и опции сборки |

Тулчейн и пресеты описаны в `docs/build/toolchain.md`.

## Как поддерживать

Карта обновляется в том же изменении, что и код, — см. `.claude/CLAUDE.md`, раздел «Документация и навигация по коду».

- Новая подсистема — строка в таблице и документ в `docs/<subsystem>/`.
- Изменилось назначение, расположение или зависимости — правится строка.
- Подсистема удалена — удаляются строка и её документы.

Карта перечисляет подсистемы и связи между ними. Описание внутреннего устройства, публичного API и деталей реализации в неё не переносится: для этого есть документы подсистем.
