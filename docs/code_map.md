# Карта кода

Точка входа в репозиторий. Отвечает на вопрос «где что лежит» и ведёт к подробному описанию каждой подсистемы.

Карта перечисляет подсистемы, их назначение, расположение и зависимости. Устройство подсистемы описывает её собственный документ в `docs/<subsystem>/`.

## Статус

Репозиторий в начальной стадии: код отсутствует. Ниже — запланированная структура из `README.md`. Строка появляется в таблице, когда подсистема существует в коде.

## Слои

Зависимости направлены сверху вниз. Обратных зависимостей не бывает.

```text
game      → игровая логика
runtime   → мир, ECS, сеть, стриминг, ассеты
engine    → рендер, платформа, звук, физика, анимация
libraries → bgfx, SDL3, Jolt, glm, ...
```

## Как поддерживать

Карта обновляется в том же изменении, что и код, — см. `CLAUDE.md`, раздел «Документация».

- Новая подсистема — строка в таблице и документ в `docs/<subsystem>/`.
- Изменилось назначение, расположение или зависимости — правится строка.
- Подсистема удалена — удаляются строка и её документы.

Карта перечисляет подсистемы и связи между ними. Описание внутреннего устройства, публичного API и деталей реализации в неё не переносится: для этого есть документы подсистем.
